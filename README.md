# OMNISPLORE — Global Astronomy, Space Missions & Quantum Physics Portal

Created & Engineered by **Tamojit Roy** (B.Tech CSE Alumnus, Vellore Institute of Technology, Chennai — Class of 2023).

## Key Features
- **Ultra-Responsive Multi-Device Architecture (`320px` to `4K`)**: Adaptive two-tier mobile header, touch-enabled slide-over navigation drawer with backdrop blur, `ResizeObserver`-driven WebGL & HTML5 canvases, and zero horizontal overflow.
- **Dynamic 3D WebGL Observatory (Three.js)**: Automatically cycles through 5 procedural 3D scenes on every browser refresh (Solar System Orrery, Gargantua Black Hole, CERN LHC Higgs Collision, James Webb Space Telescope, and Millisecond Pulsar & Asteroid Belt) with touch and mouse drag controls.
- **Global Space Missions Archive**: Filterable database of ISRO, NASA, ESA, Roscosmos, and JAXA/CNSA triumphs, future roadmaps, and engineering root-cause failure analyses.
- **Quantum Physics, Antimatter & LHC Lab**: Interactive 17-particle Standard Model inspector, Higgs Boson & ALPHA-g antimatter dossiers, and a live Special Relativity Lorentz time-dilation simulator.
- **High-Availability Live Science News & Dynamic 10-Q API Quiz**: Real-time Spaceflight News API v4 (`articles` + `blogs`) with pagination and OpenTDB API integration with zero-downtime local failover.
- **60FPS Space Arcade**: Playable *Kuiper Asteroid Defender* and *Gravitational Slingshot Lab* with both keyboard and mobile touch controls.

## Instant Deployment to Netlify
1. Drag and drop this folder (or `omnisplore_netlify.zip`) into **Netlify Drop** (`https://app.netlify.com/drop`), or
2. Push to GitHub/GitLab and connect to Netlify (`Publish directory: .`, no build command needed).
